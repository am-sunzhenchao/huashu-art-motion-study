# 「大模型参数」× 35 风格 · 统一镜头表（风格样片集）

任务：同一段内容，用工程支持的 35 种艺术风格各做一支 10 秒样片（1920×1080@30fps、整 10 秒、无声、无角标），供横向对比。成片文件名 = 风格中文名，见 `映射表.md`。

## 内容（贯穿三问）

1. 大模型领域经常提到的"参数"到底是指什么？
2. 参数量越大，是不是模型效果越强？
3. 为什么以前大家疯狂卷参数，而现在不怎么提及了？

## 统一分镜（每支样片：单镜头内三个节拍，画面里持续有物在动）

| 时间段 | 画面里的物 | 它在做什么 | 镜头 | 屏上字 | 做法 |
|---|---|---|---|---|---|
| 0–3 | 该风格母题的小元素（点/砖/笔画/星/珠/像素/光斑…），就是"参数"本体；其中两三颗带具体小数字（0.73、−1.2、2.4） | 各自做该风格的小循环动作（呼吸/摇曳/明灭/颤动），带数字的几颗被放大端详 | 缓推或停（近景特写） | 参数 | scenes/s<id>.js |
| 3–7 | 小元素增殖成的一大片结构（星群/织锦/马赛克墙/藤蔓网/波点海…按风格重新构图）；一只真实序列计数器 | 元素连片生长、连线蔓延，计数器滚动 1.5B → 175B → 540B → 1T+，背景随密度升级 | 缓拉远（或按风格缓推入网心），1T+ 揭示时最多一次重音 | 疯狂卷参数 | scenes/s<id>.js |
| 7–10 | 三件该风格的具体物：一摞书或卷轴（数据）、齿轮或罗盘（训练方法）、油灯或火盆或电池（算力）＋已长成的参数结构 | 增殖停住；三物依次升起归位，参数元素从"变多"转为"变亮变精"（描金/发光/上釉/点睛），网络收稳 | 停或缓拉收全貌，落在三物归位＋收稳的动作上 | 参数之外 | scenes/s<id>.js |

## 共同约束（每支都要守）

- **一片一风格**：只用该风格配方卡（`references/风格配方/<id>.md`）的色板和渲染器；技法照卡，构图必须为"参数"题材重新设计，**不搬速通片的房间构图**（窗左上、猫左下、少女右端杯）。
- **无角色**：不画人脸、不画机器人、不给物加脸；主角是"参数之物"本身。
- **字**：优先画成该风格的材料（路径字/刻线/贴金/盖章）；中文用 LXGWWenKai-500（现代风格可用 NotoSansSC-500/700/800），计数数字用该风格字体，全部先 `U.assertGlyphs` 验字形。字避开 y>880；字长在该风格的物上（标签/铭文/印章）更好，不做居中金句卡。
- **镜头**：整支一个连续运镜思路（近景→展开→收稳），看得清就停、过渡用缓、重音最多一次（1T+ 揭示）；不得全片死镜头，也不得每拍都快推。
- **画要活**：主动作（增殖/计数）外，至少 2 个母题小循环；做旧（剥落/划痕/污渍）只上背景。
- **确定性**：随机全部用种子（`U.rng`）；同一时刻渲两次逐像素一致（qa 会量）。
- **性能**：静态部分 `PAINT.cached`；每帧 ≤150ms。
- **色板**：写分镜时抄卡内色值；风格卡自带蓝紫系（蒸汽波、新海诚、莫奈、毕加索蓝等）时在表前加「允许蓝紫：风格卡自带」。

## 每支的验收（全过才算完）

```sh
# 1. 静帧（节拍处）＋程序化读帧
uv run --with playwright python 参数风格对比/代码工程/render.py --film s<id> --solo s<id> --stills 1,3.5,5.5,8.5 --out 参数风格对比/静帧/<id>
uv run --with pillow --with numpy python 参数风格对比/工具/查帧.py 参数风格对比/静帧/<id>
# 2. qa 数字
uv run scripts/qa.py --project 参数风格对比/代码工程 --film s<id> --ids s<id> --fps 30 --sub-band 0 --out 参数风格对比/qa/<id>
# 3. 出片
uv run --with playwright python 参数风格对比/代码工程/render.py --film s<id> --solo s<id> --from 0 --to 10 --fps 30 --no-counter --out 参数风格对比/成片/<中文名>.mp4
# 4. 分镜 lint
uv run scripts/storyboard_lint.py 参数风格对比/分镜/<中文名>.md
```

qa 验收线：确定性 ✓、运动 0.3–8%、静止帧对 ≤40%、跳变 0（有意的节拍闪/镜头事件要能解释）、ms_mean ≤150、框景 0。
读帧验收线：4 张节拍静帧无空白（std 明显大于 0）、主色都来自卡内色板、三拍构图有别的可辨（节拍帧之间的帧差 ≥3%）。
